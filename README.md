# Exercícios de Java

Este repositório contém uma série de pequenos programas em Java desenvolvidos para praticar lógica de programação e resolução de problemas matemáticos. O foco principal é a construção de algoritmos simples e eficientes.

## 💻 Sobre o Projeto

Estes exercícios fazem parte da jornada prática em Análise e Desenvolvimento de Sistemas (ADS) pela FAETERJ-RIO. Cada arquivo explora conceitos fundamentais da linguagem, como operadores matemáticos, manipulação de variáveis e estruturação de código.

## 📂 Arquivos do Repositório

* **Area_Perimetro.java**: Cálculo de geometria básica.
* **CalculadoraMedia.java**: Algoritmo para cálculo de médias aritméticas.
* **ConversorTemperatura.java**: Conversão entre diferentes escalas térmicas.
* **ConversorTempo.java**: Lógica para conversão de unidades de tempo.
* **SalarioInss.java**: Cálculo de descontos previdenciários e salário líquido.

## 🚀 Como executar

Para rodar qualquer um destes arquivos, certifique-se de ter o Java JDK instalado na sua máquina. Você pode compilar e executar diretamente pelo terminal ou utilizar o botão de "Run" (Executar) da extensão do Java no próprio VS Code.
